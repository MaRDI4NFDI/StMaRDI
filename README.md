# StMaRDI

Welcome to the Graphical Modeling and Causal Inference (GMCI) website. Our goal is to provide a place for FAIR (= Findable, Accessible, Interoperable, and Reusable) GMCI research and analyses. For this, we moderate the [GMCI Zenodo community](https://zenodo.org/communities/mardigmci/) where curated topical datasets as well as analysis repositories are stored. 
This git project contains the code to the [GMCI analysis library website](https://st-mardi.quarto.pub/gmci/). It features exemplary statistical notebooks that showcase advances in methodology and presents new applications. 

We allow for (a) topical dataset contributions, and (b) for topical notebook contributions. For more details, read our [contribution page](https://st-mardi.quarto.pub/gmci/chapters/contribute.html).
